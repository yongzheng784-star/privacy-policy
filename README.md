# privacy-policy

This repository hosts public compliance files for the Android app **美剧TV**.

## Public URLs

- Privacy Policy: https://yongzheng784-star.github.io/privacy-policy/privacy_policy.html
- app-ads.txt: https://yongzheng784-star.github.io/app-ads.txt

## Files

- `privacy_policy.html`
  - Public privacy policy page for the app.
  - Includes disclosure for advertising services, advertising ID, IP address, device information, ad impressions, ad clicks, anti-fraud, analytics, and consent management.

- `app-ads.txt`
  - Authorized digital sellers file generated from Appodeal.
  - Should be published at the root of the GitHub Pages domain.

## App Information

- App name: 美剧TV
- Package name: `com.sl.yingshidaren`
- Platform: Android / Google Play
- Monetization platform: Appodeal
- Current ad formats: Banner and Interstitial

## Third-Party Advertising Services

The app uses Appodeal mediation and related advertising services, including:

- Appodeal
- Unity Ads
- BidMachine
- Bidon

These services may process advertising identifiers, IP address, device information, ad request data, ad impression data, ad click data, and anti-fraud signals according to their own privacy policies.

## Maintenance Notes

When advertising networks or SDK adapters change, update both:

- `privacy_policy.html`
- `app-ads.txt`

After updating `app-ads.txt`, confirm that the final file is available at:

```text
https://yongzheng784-star.github.io/app-ads.txt
```

Do not publish placeholder seller IDs such as `Publisher_ID` or `Business_ID`.
